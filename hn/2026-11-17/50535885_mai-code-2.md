**Microsoft představil MAI Code 2 a Code 2 Flash. Cílí na každodenní firemní kódování**

Hacker News · lemonish97 · 17. listopadu 2026, 19:25 · 324 bodů / 145 komentářů · [diskuse](https://news.ycombinator.com/item?id=50535885)

Microsoft uvedl dvojici kódovacích modelů MAI Code 2 a MAI Code 2 Flash postavenou pro každodenní firemní programování. Větší Code 2 má zvládat dotažení kódu do produkce, hluboké ladění, implementace napříč soubory, uvažování nad celým repozitářem i tvorbu rozhraní, menší Flash je určený pro vysvětlování kódu ve velkém, cílené úpravy, rutinní opravy a rychlé iterace.

Firemní oznámení láká hlavně na poměr ceny a výkonu. V průměru čtyř benchmarků zaměřených na běžnou práci v GitHub Copilot prý Code 2 podává 98 % výkonu GPT 6.1 Sol za 40 % ceny a 96 % výkonu Claude Opus 5.5 za pouhých 5 % ceny, ve slepém hodnocení frontendu pak recenzenti dávali přednost jeho výsledkům před GPT-6 Sol v 64 % případů. Flash se má vyrovnat GPT-6 Luna a Claude Haiku 5.5 za 65 %, respektive 20 % ceny, Microsoft ale zároveň otevřeně přiznává, že modely zatím nejsou laděné na těžší problémy typu fundamentálního výzkumu nebo velmi dlouhých agentních úloh.

Největší debatu vyvolala právě čísla. Uživatel zf00002 píše, že je skeptický, ale líbí se mu, že Microsoft poměřil modely rovnou s nejlepší konkurencí, uživatel user43928 ale upozorňuje, že Code 2 je v testu nasazený s padesátiprocentní promo slevou a srovnává se s maximálním úsilím uvažování u Opus 5.5 a 6.1 Sol. Uživatel UncleOxidant by chtěl vidět i srovnání cen s DeepSeek, GLM a Qwen, což ostatně zapadá do širší výtky, že americké žebříčky čínské modely přehlížejí.

Druhá linka řeší, kdo na levnější modely vlastně přejde. Uživatel dude250711 se obává, že průměrný podnik kvůli úsporám přestane platit pořádné modely od Anthropicu a přesedlá na Microsoft, uživatel eddythompson80 kontruje, že kdo modely reálně používal, toho nepřesvědčí, a clueless šéfové jsou stejně hlavní zákazník Microsoftu. Uživatel CharlieDigital naopak říká, že velkou část práce dnes předává Haiku a Luně, takže ho poměr ceny a výkonu upřímně zajímá, uživatel eminence32 pak dodává, že snižování nákladů by měli zákazníci spíš vítat.

Řešila se i značka a původ. Uživatel therein se ptá, jestli Microsoft konečně vzdal cpání brandu Copilot všude, uživatel InsideOutSanta připomíná, že oba nové modely jsou dostupné právě v GitHub Copilot, a uživatel contextfree vysvětluje, že Copilot se má nově používat spíš pro konkrétní harness vycházející z GitHub Copilot CLI. Uživatel abraxas se ptá na základy modelů, jestli jde o vlastní práci nebo převzaté otevřené modely, a uživatel tomatoandbasil odkazuje na text Microsoftu o vlastním pre-tréninku. S úsměvem to uzavírá uživatel gltwelv rýpnutím, že Microsoft oznamuje MAI Code na webu, který vypadá jako vibe-coded Claude, a odbočka uživatele liuliu k tomu, proč má oznámení patkové nadpisy a bezpatkové tělo.
